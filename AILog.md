# AI Log

A running record of code written by Claude (Claude Code) in this repository,
kept alongside [AIUsage.md](AIUsage.md). It only covers code the AI actually
wrote. Advice, reviews and code I wrote myself are not logged here.

Newest entries first. Format:

```
## YYYY-MM-DD: short title
- Files: paths touched
- What: 1–3 lines on what was written or changed
- Why: deadline / boilerplate / tests / tooling (see AIUsage criteria)
- Later: (optional) "rewritten by me on YYYY-MM-DD", etc.
```
